# Restaurant Landing Page

A modern and responsive restaurant landing page built using **HTML5** and **CSS3**. The project features a premium dark theme, clean user interface, and responsive layout for different screen sizes.

---

## ✨ Features

* Responsive Design
* Modern Dark Theme
* Hero Section
* Featured Menu
* About Us Section
* Gallery Section
* Contact Information
* Smooth Scrolling
* Hover Effects

---

## 🛠️ Built With

* HTML5
* CSS3
* Flexbox
* Media Queries

---

## 🔗 Live Demo

[View Live Website](https://zubair-dev786.github.io/Restaurant-Website/)

---

## 🎯 Purpose

This project was created to practice responsive web design, Flexbox, reusable CSS, and building modern landing pages using only HTML and CSS.
